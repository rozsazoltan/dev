# Completion Verification

- Compare the finished result against the original request and acceptance criteria.
- Inspect the actual changed files and their final contents, not the summary of the change.
- Run the relevant checks, tests or builds and read their output before reporting.
- Confirm that no required step is still unfinished, deferred or unverified.
- Update the planning files with the final status.
- Report remaining limitations, unverified behavior and skipped checks honestly.
- A context compaction, a tool interruption or a resumed session never proves completion.
- Do not report success from a plan file, a previous summary or a green check that later edits invalidated.
